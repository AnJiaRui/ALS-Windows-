# ALS 时间悬浮窗

这是一个适用于 Windows 无边框窗口游戏的轻量时间悬浮窗。它作为独立桌面窗口运行，不会注入、读取或修改游戏进程。

## 运行

安装已启用 Tkinter 的 Windows 版 Python，然后运行：

```powershell
python main.py
```

悬浮窗启动后会显示本地 12 小时制时间，默认位于屏幕左上方。窗口无边框、半透明，不会作为普通窗口按钮显示在任务栏中；可以通过系统托盘区的图标打开控制菜单。

[启动.bat](启动.bat)或[启动.ps1](启动.ps1) 会在没有控制台窗口的情况下启动 Python，随后立即退出，不会一直打开命令窗口。

## 快捷键

- **按住 Ctrl + 方向键**：平滑移动悬浮窗。按住时会逐渐加速，松开后会逐渐减速；也可以同时按两个方向键进行斜向移动，斜向速度不会额外变快。
- **Ctrl + Shift + Q**：退出程序。

程序会全局监听这些按键，但不会独占快捷键。因此，即使其他应用也使用 Ctrl + 方向键，悬浮窗仍可正常启动。程序不会拦截或更改发送给其他应用的键盘输入。

## 系统托盘菜单

左键单击 Windows 任务栏时钟旁的悬浮窗图标，即可打开菜单：

- 显示或隐藏时钟。
- 选择字号（24、32、40 或 48），也可以输入自定义字号。
- 选择预设时间颜色，或打开自定义颜色选择器。
- 调整悬浮窗透明度，范围为 20% 至 50%。整个范围内时钟都会保持可见的半透明状态；最高透明度为 50%，默认值为 43%。
- 开启或关闭**登录 Windows 后自动启动**。程序会在当前 Windows 用户的注册表 `Run` 项中添加或移除启动项，不需要管理员权限。
- 退出程序。

选定的字号和颜色会保存到当前 Windows 用户的设置中，并在下次启动时恢复。

透明度滑块会即时预览更改；点击“应用”后保存，点击“取消”则恢复到调整前的值。旧版本保存的透明度设置会自动转换。悬浮窗保持置顶且不会跟随鼠标；通常情况下，Windows 会将鼠标指针显示在应用窗口上方。

菜单窗口Windows 11 上使用 DWM 圆角，在 Windows 10 上使用圆角窗口区域 (Windows 10 部分设备可能失败)。

托盘图标使用随程序提供的 `tray_icon.ico`，该图标由带透明棋盘背景的时钟图片生成，包含多种尺寸。请将它放在 `main.py` 旁边。程序会在创建窗口前启用 Windows 每显示器 DPI 感知，并使用灰度字体抗锯齿和逐像素 alpha 混合，让文字边缘平滑且避免黑边。

程序不需要安装其他 Python 软件包。

## 注意

悬浮窗始终置顶，并会将鼠标输入穿透到下方的游戏。能否显示在游戏画面上方，取决于游戏显示模式、Windows 或反作弊软件的行为。本程序不会尝试绕过这些限制。

请将游戏设置为无边框窗口。
